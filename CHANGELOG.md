# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-04-21
### Added
- Initial project structure for BookSync (Audible to Audiobookshelf sync).
- Database service for local storage.
- Audible service for metadata retrieval and sync.
- Scan service for network folder monitoring.
- Export service for audiobook conversion and organization.
- Modern React/Tailwind renderer with Library view, Settings, and Logs.
- Responsive UI design for various window sizes.
- Git repository initialization.
